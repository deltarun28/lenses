## Principle

When each additional user increases the value to existing users, growth compounds and
position becomes defensible.

## Explanation

Most products deliver constant value per user. A network effect breaks that: the tenth
participant makes the product better for the previous nine. The result is a reinforcing
loop where early advantage becomes structural, and where being second-best with more
users beats being best with fewer.

Two distinctions matter. Direct effects come from users of the same kind — communication
tools, standards. Indirect ones run between groups: buyers attract sellers who attract
buyers. Indirect effects are harder to start, because you must solve both sides at once.

They also run in reverse. A network losing participants loses value for those remaining,
which accelerates the loss. The same mechanism that made it defensible makes the decline
fast once it begins.

## Military Example

Coalition interoperability standards gain value with each nation that adopts them: the
data link that everyone speaks is worth more than the technically superior one used by
three partners. This is why standards adoption is negotiated politically rather than
selected on merit, and why a superior incompatible system is often the wrong choice.

## Leadership Example

An internal tool becomes genuinely useful once most teams use it, because the value is
in shared visibility. Below that threshold it is overhead with no benefit, which is why
partial rollouts stall — the teams that adopted early experience cost and no return, and
their unenthusiastic reports discourage the rest. Getting past the threshold quickly
matters more than getting the tool right.

## Product Example

A marketplace with few sellers offers buyers little, and few buyers make it unattractive
to sellers. Nothing about the product solves this. The usual answers are to subsidise one
side, to constrain the market geographically until it is dense, or to provide standalone
value that does not depend on the network until the network exists.

## Questions

- Does each new user make this better for existing users, or just add revenue?
- Is the effect direct, or does it run between two groups that both need solving?
- What is the threshold below which this has no value at all?
- If participants started leaving, how quickly would the rest follow?

## Common Misuse

The term is claimed for almost every product, including ones that simply benefit from
scale — cheaper unit costs are economies of scale, not a network effect, and the
strategic implications are entirely different. Effects are also frequently local rather
than global: a marketplace can be dense in one city and worthless in the next, so
national user counts describe nothing. And a network effect is not a permanent moat;
it holds only while switching remains costly.
